# 洞府经营规则 v0.3.0

本表对应 `src/core/economy-rules.js`、建筑定义和职业定义。每次改数值后，应重跑 `tests/economy-scenarios.mjs`。

| 规则 | 当前值 | 生效条件 |
| --- | ---: | --- |
| 开局粮食 / 材料 / 香火 | 120 / 100 / 0 | 新档；旧档保留原数值 |
| 基础仓储上限 | 240 / 160 / 100 | 每座仓库再增加 240 / 160 / 120 |
| 仙人耗粮 | 每人每游戏小时 1 | 始终消耗；不足时粮食停在 0，心情下降 |
| 农务产粮 | 每工作小时 10 × 效率 | 住在居所、灵田上岗、可通行、06:00–18:00、精力大于 0 |
| 器作产材料 | 每工作小时 4 × 效率 | 同上，工作地点为工坊 |
| 执事产香火 | 每工作小时 2 × 效率 | 同上，工作地点为仓库 |
| 工作效率 | (0.5 + 精力/200) × (0.5 + 心情/200) | 精力与心情均为 0–100，效率范围为 0.25–1 |
| 膳堂 | 每座在岗膳堂节粮 25%，上限 50% | 有执事在膳堂实际工作才生效；在岗时改善心情 |
| 休息恢复 | 每游戏分钟 +0.08 精力 | 仙人在居所休息；无居所待命时每分钟 +0.03 |
| 野外采集 | +12 粮食、+6 材料；耗时 1 游戏小时、消耗 12 精力、2 心情 | 每 6 游戏小时可用一次；选精力最高的仙人，受仓储上限约束 |

开局推荐：先建两栋居所、灵田、工坊，建成后自动入住与派工；草地可以通行，道路提供更快通勤。保持建筑入口周围有空地。两名仙人开始生产后，再补仓库和膳堂。材料耗尽时可用野外采集恢复。较远的通勤会减少实际上工时间。

## 存档与迁移

- 存档版本仍为 1。v0.2.4 之前的存档继续读取，新字段 `lastRescueAt` 缺失时默认为从未采集。
- 新档初始材料改为 100；旧档资源数值不改写。
- 地图修订号 `mapRevision` 缺失时默认为 0，旧居民抵达建筑后会重新验证通路。
- `createInitialSave` 的旧样例结构已删除，实际存档结构由 `serializeGameState` 负责。
