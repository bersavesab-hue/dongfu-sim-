# 洞府经营

一个面向手机的轻量 2D 洞府经营模拟游戏。

## 当前版本

- 版本：0.3.0
- 阶段：可试玩的经营循环
- 玩法：建造居所和工作建筑，自动安排仙人入住、生产；步行可绕开建筑，铺路可加快通勤；本地自动存档。

## 第一阶段验收

1. 能拖动和缩放地图。
2. 能在中央 20×20 建造区放置、移动、旋转、拆除建筑。
3. 住宅、农田、工坊、食堂、仓库形成最小资源循环。
4. 3 名仙人能够入住、工作、休息。
5. 能保存并读取进度。

## 目录

- `docs/`：规划、规则和技术约定
- `src/core/`：与平台无关的规则和数据
- `src/world/`：地图、地形、资源点和寻路
- `src/render/`：Canvas 渲染
- `src/platform/`：Web 与抖音小游戏适配层
- `tests/`：规则和存档测试

所有新增功能必须同步更新 `CHANGELOG.md`，禁止保留重复入口、临时占位实现和旧接口。
